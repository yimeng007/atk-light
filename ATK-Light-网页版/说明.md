# ATK-Light 使用说明

面向使用者的功能说明。**协议实现细节不在本文档内**——需要自己改代码的，看
[README 的「技术要点」](../README.md#tech) 和 `tools/usb-capture/`。

## 三种用法

| 方式 | 适合谁 | 怎么做 |
| --- | --- | --- |
| **解压即用** | 绝大多数人 | 从 Releases 下载 `ATK-Light-2.0.0.zip`，解压后双击 exe |
| **纯网页版** | 想用自己浏览器的人 | Chrome / Edge 直接打开 `index.html` |
| **源码运行** | 要改代码的人 | 本机装好 Electron，双击 `启动托盘版.bat` |

三种方式共用同一份前端代码，行为一致。

## 界面说明

### 设备卡片

顶部显示设备名、连接状态、连接方式、轮询率、当前档位、电量。

- **电量**：显示百分比；**鼠标悬停**可看到电压（mV）和充电状态
- **状态徽标**：在线 / 睡眠 / 离线（判定规则见下）
- 卡片可展开，展开后是全部可调项

### 可调项

| 分组 | 项目 |
| --- | --- |
| 轮询率 | 125 / 250 / 500 / 1K / 2K / 4K / 8K |
| DPI | 最多 8 档，点档位切换当前档 |
| 按键映射 | 5 个可改键（左 / 右 / 中 / 前进 / 后退） |
| LOD | 0.7 ~ 1.7 mm，步长 0.1 |
| 按键防抖 | 0 / 1 / 2 / 4 / 8 / 15 / 20 ms |
| DPI 灯效 | 模式 + 亮度 + 速度 |
| 传感器采样率 | 基础 / 绝鲨竞技 / 绝鲨竞技 MAX |
| 传感器修正 | 移动同步 / 直线修正 / 波纹修正 |
| 超远距离 | 动作按钮（本次连接有效，重连复位） |
| DPI 快捷切换 | 开关 |
| 休眠时间 | 30 秒 ~ 30 分 |

## 设备显示规则（重点）

面板按「能不能真的读到数据」判断状态，不猜：

| 状态 | 含义 | 多久报出 |
| --- | --- | --- |
| **在线** | 能读到数据 | 实时 |
| **睡眠** | 设备还在（枚举得到），但读不到数据 | 超过「设备自身休眠设置 + 10 秒」 |
| **离线** | 从 HID 设备列表里彻底消失 | 插拔瞬间（<1 秒） |

**几个实际会遇到的场景**：

- **插着接收器但鼠标没动** → 显示「睡眠」。这是对的，设备确实没醒
- **拔掉接收器** → 立刻「离线」，电量和各项数值变成 `—`（不显示旧数据）
- **晃一下鼠标** → 3 秒内回到「在线」
- **休眠设成 30 分钟** → 面板最多也要 30 分钟才发现设备异常（跟随你的设置，不是 bug）

## 打开 ATK HUB 网页的跳转方式

面板底部「打开 ATK HUB 网页」按钮会调用系统默认浏览器打开官方 HUB。

具体做法是通过**主进程的 `shell.openExternal`**，不是在渲染层直接跳转——
因为渲染进程跑在 sandbox 里，拿不到 `shell` 模块。

## 托盘定位逻辑

面板始终出现在**托盘图标正上方**；如果托盘在屏幕顶部，则改为向下弹出。
靠近屏幕边缘时会自动贴边，不会跑出可视区域。

## 想改哪里

如果你要改功能或适配别的型号，代码集中在三个文件：

| 文件 | 职责 |
| --- | --- |
| `index.html` | 界面 + 全部业务逻辑（单文件，无构建步骤） |
| `tray-main.js` | 托盘宿主：窗口显隐 / 自启动 / 退出 / 单实例 |
| `preload.js` | 渲染层能调哪些主进程能力（白名单） |

**协议相关的方法说明**看 [README 技术要点](../README.md#tech)；
**怎么抓包定位字段**看 [`tools/usb-capture/README.md`](../tools/usb-capture/README.md)。

⚠ **本项目只适配 ATK 设备**，换别的品牌需要自己重新测协议。

## 已知限制

- 按键映射只开放 5 个键（其余是设备内部固定功能，官方 HUB 也不开放）
- 改键动作只收录了已确认的 7 项，板载切换 / DPI± / 键盘映射等尚未对照
- 板载配置档、宏：暂无界面
- 本型号无蓝牙（官方参数是 Wired / 2.4GHz）
- 为实现零闪烁，面板窗口不再真正隐藏（常驻内存约 30-50MB，不占任务栏、不挡鼠标）

## 数据存放

设备记录与偏好设置存在本地的 `localStorage`（Electron 用户数据目录下）。
**不联网、不上传任何数据。**

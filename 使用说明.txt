ATK-Light v2.0.0 使用说明
================================================================

一、启动
双击 ATK-Light-2.0.0.exe 即可。无需安装、无需 .NET 或运行库，
Windows 7 / 8 / 8.1 / 10 / 11 均可直接运行。

二、找不到面板？
面板是托盘应用，不占用任务栏，默认停在右下角托盘区。

  想打开        → 单击托盘里的 ATK-Light 图标（再单击收起）
  图标被折叠    → 点任务栏的 ^，把图标拖到外面固定住
  彻底找不到了  → 重新双击 exe（已在运行会唤起，不会开第二个）

注意区分：
  「点面板外面」= 只是收起，程序仍在托盘里运行
  「退出应用」  = 真正结束进程

三、第一次连接设备
  1. 点面板里的「连接设备」
  2. 在弹出的列表中选择带 0xFF02 通道的 ATK 设备
  3. 授权后即可读取并调节各项设置

四、功能一览
  轮询率 / DPI 档位 / 按键映射 / LOD / 按键防抖 / DPI 灯效 /
  传感器采样率 / 传感器修正 / 超远距离 / 休眠时间 / 恢复出厂设置

  电量：显示百分比，鼠标悬停可看到电压（mV）与充电状态
  通知：满电、低电量会弹系统通知（需在系统里允许通知权限）

五、安全提示
  「恢复出厂设置」会改写设备的按键、轮询率、LOD、DPI、灯效与传感器修正，
  执行后立即生效、不可撤销。请确认理解后果后再使用。

六、数据存放
  设备记录与偏好设置存于本地（Electron 用户数据目录下的 localStorage）。
  本软件不联网、不上传任何数据。
